# Code Generator

Generate code in 20+ languages.

## Usage

```bash
./code_gen.py python "Calculate fibonacci numbers" -o fib.py
./code_gen.py javascript "Create web server" -o server.js
./code_gen.py java "Sort array" -o Sort.java
```

## Supported Languages

Python, JavaScript, TypeScript, Java, C++, C, C#, Go, Rust, PHP, Ruby, Swift, Kotlin, Dart, R, Scala, Perl, Bash, PowerShell, Lua
