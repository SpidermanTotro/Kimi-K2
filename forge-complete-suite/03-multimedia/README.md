# Multimedia Processor

Process video, audio, and images.

## Usage

```bash
# Video info
./media_processor.py video input.mp4

# Convert video
./media_processor.py video input.mp4 --operation convert --output output.avi

# Extract audio
./media_processor.py video input.mp4 --operation extract_audio --output audio.mp3

# Audio processing
./media_processor.py audio song.mp3

# Image processing
./media_processor.py image photo.jpg
```
