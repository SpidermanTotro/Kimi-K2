NEXUS AI - Portable Edition
============================

Setup:
1. Copy .env.example to .env
2. Add your OpenAI API key to .env
3. Run: ./run-nexus.sh

Requirements:
- Python 3.11+
- OpenAI API key
- Internet connection

Features:
- Multi-agent AI system
- GPT-4 and o1 reasoning models
- Safe code execution
- Advanced reasoning capabilities
