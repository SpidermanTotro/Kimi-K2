Overview

Kimi K2 is a state-of-the-art mixture-of-experts (MoE) language model with 32 billion activated parameters and 1 trillion total parameters. This documentation provides comprehensive guides for deployment, development, and extending Kimi K2's capabilities.

# Example: Basic chat completion
from openai import OpenAI

client = OpenAI(base_url="http://localhost:8000/v1", api_key="not-needed")

response = client.chat.completions.create(
    model="kimi-k2",
    messages=[{"role": "user", "content": "Hello!"}],
    temperature=0.6
)

print(response.choices[0].message.content)
