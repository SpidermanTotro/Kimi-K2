## 🌐 REMOTE CONNECTIONS (NEW!)

THE FORGE now supports remote access like GitHub Codespaces!

### Local Access
- **Browser**: `http://localhost:5000`
- **Network**: `http://YOUR_IP:5000`
- **WebSocket**: `ws://YOUR_IP:9090`

### Remote Access Options

#### 1. SSH Access
```bash
ssh -p 2222 user@YOUR_IP
```

#### 2. HTTP Tunnels (Free!)

**localhost.run** (no signup needed):
```bash
ssh -R 80:localhost:5000 ssh.localhost.run
```
Get instant public URL!

**serveo.net** (no signup needed):
```bash
ssh -R forge:80:localhost:5000 serveo.net
```
Access at: `https://forge.serveo.net`

**ngrok** (free tier):
```bash
ngrok http 5000
```
Get custom subdomain!

#### 3. WebSocket for Real-Time Sync
Connect to `ws://YOUR_IP:9090` for:
- Real-time code collaboration
- Live cursor tracking
- Instant updates

### Setup Remote Connections
```bash

```
