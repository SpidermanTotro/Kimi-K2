## 🚀 Deployment

### Quick Start

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/SpidermanTotro/Kimi-K2.git
   cd Kimi-K2/THE_FORGE_AI
   ```

2. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Start the Application:**
   ```bash
   # Start web server
   python -m http.server 8050
   
   # In another terminal, start backend
   cd src
   python main_integration.py
   ```

4. **Access the Application:**
   - Web Interface: http://localhost:8050/web/
   - API Documentation: http://localhost:8050/docs/

### Docker Deployment

```bash
# Build and run with Docker Compose
docker-compose up -d

# Or build manually
docker build -t forge-ai .
docker run -p 8050:8050 forge-ai
```

### Cloud Deployment

**AWS Deployment:**
```bash
# Deploy to AWS ECS
./deploy/aws.sh
```

**Google Cloud:**
```bash
# Deploy to Google Cloud Run
./deploy/gcp.sh
```

**Azure:**
```bash
# Deploy to Azure Container Instances
./deploy/azure.sh
```

## 🔧 Configuration

### Environment Variables

```bash
# Database Configuration
DATABASE_URL=postgresql://user:pass@localhost/forge_ai
REDIS_URL=redis://localhost:6379

# Security
SECRET_KEY=your-secret-key-here
JWT_SECRET=your-jwt-secret
```
