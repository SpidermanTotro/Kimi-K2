## Submission Checklist

Before submitting, ensure:

- [ ] Plugin follows the plugin development guide
- [ ] All tests pass
- [ ] Documentation is complete
- [ ] Code is well-formatted and linted
- [ ] Security review completed
- [ ] Plugin registered in registry.json

## How to Submit

1. Fork the Kimi-K2 repository
2. Add your plugin to the `plugins/` directory
3. Update `plugins/core/registry.json` with your plugin information
4. Create a Pull Request with this template filled out
5. Address any review feedback

## Review Process

Your plugin will be reviewed for:
- Code quality and style
- Security vulnerabilities
- Performance implications
- Documentation completeness
- Test coverage
- Compatibility

Please allow 7-14 days for initial review.
