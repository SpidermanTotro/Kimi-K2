## 🚀 HOW TO USE

### THE FORGE AI

**Linux:**
```bash
# Extract
tar -xzf TheForgeAI-Portable.tar.gz
cd TheForgeAI-Portable

# Run
./run-forge.sh

# Access
# Browser opens automatically to http://localhost:9001
```

**Windows:**
```
1. Extract TheForgeAI-Windows.zip
2. Double-click run-forge.bat
3. Browser opens automatically
```

### NEXUS AI

**Linux:**
```bash
# Extract
tar -xzf NexusAI-Portable.tar.gz
cd NexusAI-Portable

# Setup
cp .env .env.local
# Edit .env.local and add: OPENAI_API_KEY=sk-...

# Run
./run-nexus.sh
```

**Windows:**
```
1. Extract NexusAI-Windows.zip
2. Edit .env with your OpenAI API key
3. Double-click run-nexus.bat
```
