## 🚀 HOW TO USE

### THE FORGE AI

**Linux:**
```bash
tar -xzf TheForgeAI-Portable.tar.gz
cd TheForgeAI-Portable
./run-forge.sh
# Opens http://localhost:9001
```

**Windows:**
```
1. Extract TheForgeAI-Windows.zip
2. Double-click run-forge.bat
3. Browser opens automatically
```

### NEXUS AI

**Linux:**
```bash
tar -xzf NexusAI-Portable.tar.gz
cd NexusAI-Portable
# Edit .env with OpenAI API key
./run-nexus.sh
```

**Windows:**
```
1. Extract NexusAI-Windows.zip
2. Edit .env with API key
3. Double-click run-nexus.bat
```

### ChatGPT Parser

**CLI:**
```bash
python chatgpt_parser.py export.zip --all output
```

**GUI:**
```bash
python chatgpt_parser_gui.py
```
